# IQPack

A Minecraft 1.7.10 modpack built on Forge and the GT New Horizons ecosystem.

## Installation

Mods are handled by mod-director and are not tracked in this repository. Configs, scripts, and resource packs live here. Install the pack through Prism Launcher and let mod-director fetch the mods.
